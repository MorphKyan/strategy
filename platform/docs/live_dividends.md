# 实盘股息自动记账

`LivePortfolio.plan()` 和 `mark_to_market()` 使用 `data/platform_dividends.csv` 的登记日、除息日、支付日及每份股息计算权益，无需用户确认到账。测试或独立部署可用 `live.dividends_path` 指定数据文件。

- 以登记日收盘持仓确定权益。登记日之后卖出不影响已取得的股息，登记日后买入不补发股息。
- 除息日确认应收，计入总资产；支付日将应收转为现金。股息不作为外部入金，不增发组合份额，不调整持仓成本。
- 中间日期未执行任务时，下次运行补记截至估值日已发生的事件。事件及到账标记随 `portfolio_state.json` 的 `live_accounting` 保存，重复运行及重启不重复加现金。
- 人工对账仍以传入现金为真值。传入日期及之前的到账已经包含在现金中，自动流程不再叠加；尚未到账的权益继续保留。
- 老账户首次启用时，以已有状态日期作为现金覆盖日期，避免重建历史中的分红再次到账。登记日早于首次持仓快照时，优先使用可用的历史成交流水恢复持仓；没有历史依据的权益不猜测。

股息来源必须包含相应事件，本功能不负责抓取分红公告。真实买卖仍需更新实际持仓；自动分红依据最近一次真实持仓以及保存的历史快照计算。

日报的 `positions_value` 含应收股息，与既有历史重建口径一致。已实现损益通过总盈亏减浮盈计算，自检改为与成交流水成本结转、现金股息及自动确认权益比较，正常股息无需调高容差。
