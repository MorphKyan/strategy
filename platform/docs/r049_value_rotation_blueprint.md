## 0. 课题定位

R039（行业动量轮动）当日验收 Failed——败因是鞭打与 V 型反转，本质是"追高"在 A 股行业层面不成立。
R049 是同一卫星仓研究线的**第二次尝试，信号方向相反**：不追涨，而是买**相对自身历史便宜**的行业（左侧价值 / 均值回归）。

**核心问题（也是唯一要回答的问题）**：在同一个 16 行业池、同一套执行口径下，
**"按估值分位选便宜的行业"能否打赢"持有全部行业等权"？**

对照基线沿用 R039 留下的 `domestic_industry_equal_weight.yaml`（同池、同费用、月频等权），
不与 R038 核心仓对比——两者目标不同（卫星求弹性、核心求纪律），放一起比是范畴错误。

三条纪律先立住（继承 R039 §0.1）：
1. **组合层隔离**：独立配置、独立组合 ID（`sim_r9_*` / `live_r9_*`），卫星仓表现不反哺核心仓参数。
2. **仓位标尺**：卫星仓占比由用户另定（讨论基准 10–20%），本课题回撤 25–30% 属正常预期。
3. **简单纪律优先**：v1 参数全部先验常数，**零调参、零搜索**，冻结后直接验收（R028/R037 两连败 vs R038 一次通过的教训）。

## 1. 数据基础（2026-07-25 已入库，事实而非计划）

估值数据来自 Wind `AIndexValuation`，经 `scripts/ingest_index_valuation.py` 清洗入库为
`data/index_valuation/<INDEX_CODE>.csv`（列 `trade_date,pe_ttm,pb_lf,dividend_yield,turnover,mv_total,con_num`）。
ETF↔跟踪指数映射在 `data/etf_index_map.csv`（可入库，公开信息，带 `verified_by` 溯源列）。

**ETF 本身没有 PE/PB**——其估值是跟踪指数的估值（ETF 全复制/抽样复制，持仓≈指数成分）。

### 1.1 三条硬约束（实测得出，直接决定设计）

**① 全池共同窗口自 2020-03-16 起，至训练截止约 5.3 年。**
卡点是家电 ETF 159996（2020-03-16 上市），**不是估值数据**——估值多数可回溯至 2013。
满足 AGENTS.md ">3 年"硬规则，但窗口偏短，报告须如实声明。

**② 五个行业在回测起点算不出完整 5 年估值分位**（估值数据首日晚于 2015-03-16）：

| 行业 | 指数 | 估值首日 | 回测起点前历史 |
|---|---|---|---|
| 钢铁 | 930606.CSI | 2015-03-31 | 5.0 年（差 15 天） |
| 家电 | 930697.CSI | 2015-07-07 | 4.7 年 |
| 新能源车 | 930997.CSI | 2017-07-19 | 2.7 年 |
| 科技综合 | 931087.CSI | 2019-03-20 | **1.0 年** |
| 通信 | 931079.CSI | 2019-04-25 | **0.9 年** |

设计处置：**历史不足 `min_history` 的行业当月不参与选择**（不降级、不用"发布以来分位"充数）。
理由：分位在样本极短时噪声极大，用它下注等于赌噪声；没有信号就不下注，比硬凑一个信号诚实。

**③ PB 必须是主指标，PE 只能是辅助。**
PE_TTM 缺失率：钢铁 **23.8%**、地产 **19.9%**、有色 9.5%、半导体 4.8%，其余 0%
（Wind 规则：指数 PE 为负时置空，即行业整体亏损期）。
而 **PB_LF 与股息率 0% 缺失，全指数全覆盖**。
周期股恰恰在"亏损→PE 失效"时最便宜，用 PE 会在最该出手时失明。

### 1.2 数据源可持续性（实测结论，影响 D4 上线而非本次研究）

中证官网免费接口（akshare `stock_zh_index_value_csindex`）覆盖全部 16 个指数、每日更新，
但 **① 无 PB ② 仅返回最近约 20 个交易日 ③ PE 口径与 Wind 差 4%~34% 且逐行业不同**
（医药 23.72 vs 31.84、军工 55.69 vs 68.11，方向不一，非常数偏移）。
**因此"Wind 建史 + 免费源日更"不可直接拼接**，拼接点会产生 20~30% 台阶、污染分位。

处置：本课题研究阶段**只用 Wind 静态快照**（口径全程一致，零拼接风险）。
真上线时再解决，两条路：① 每月导一次 Wind 增量（月频策略只需月末数据，一年 12 次）；
② 全面改用免费源并用免费源重算全部分位历史（需先解决 PB 缺失与历史深度）。
**上线前不建日更管道**——为尚未通过验收的策略先建管道是过早投入（R039 当日即 Failed）。

**设计启示（已纳入 §2）**：信号用**分位**而非绝对值。分位对"某指数被系统性放大/缩小一个常数倍"
免疫，天然降低将来换源的口径风险。

### 1.3 授权数据边界

Wind 导出带逐账号水印（中信证券作为 QFII 支持券商提供）。
**原始导出与清洗产物均不入库**（`.gitignore` 已挡 `/index_performance/` 与
`/platform/data/index_valuation/`），只有入库脚本与公开映射表入库。
协作者复现走"同一脚本 + 各自数据源"，不分发数据本身。

## 2. 策略规格 v1：`industry_value_rotation`

### 2.1 信号

设 V 为该行业跟踪指数的估值序列（默认 `pb_lf`），t 为信号日（月末最后一个交易日）：

```
window   = 最近 percentile_window 个交易日的 V（含 t，严格只用 <= t 的数据）
pct[i]   = (window 中 <= V[t] 的观测数) / (window 观测数)     # 时序分位，0=史上最便宜
```

**低分位 = 相对自身历史便宜 = 有吸引力。** 注意是**时序分位**（与自己的历史比），
不是横截面比大小——因为行业间 PB 绝对水平天然不可比（银行 0.6 vs 半导体 5.0 是行业属性，不是贵贱）。

### 2.2 选择规则

每个月末交易日（`rebalance_frequency = monthly`，T+1 即次月首个交易日执行）：

1. **合格集**：universe 中估值观测数 ≥ `min_history` 的行业（§1.1 硬约束②）。
2. **排名**：按 `pct` 升序（最便宜在前）。
3. **排名缓冲带（黏性）**：现任成员（`state.positions` 中数量 > 0 且属于 universe）
   只要排名 ≤ `top_n + rank_buffer` 即留任；空出的名额由未持有者中排名最靠前者依序补入。
4. **权重**：每个入选行业固定 `1 / top_n`；合格集不足 `top_n` 时缺额留现金。

### 2.3 交易触发

沿用基类 `should_rebalance` 的 `rebalance_threshold` 阈值带：成员未变且各权重相对
`1/top_n` 的漂移都在带内时**当月不交易**。这是 R038 阈值带思想在轮动语境的移植，用于压换手。

### 2.4 参数表（v1 全部先验冻结，不做任何搜索）

| 参数 | 默认值 | 依据 |
|---|---|---|
| `universe` | 16 行业 ETF | R039 准入标准（客观、与未来收益正交），见 r039 蓝图 §3.1 |
| `valuation_metric` | `pb_lf` | §1.1 硬约束③：PB 零缺失，PE 在周期股最便宜时失明 |
| `percentile_window` | `1250`（5 年） | 估值分位的行业惯例窗口；覆盖一轮牛熊 |
| `min_history` | `750`（3 年） | 短于 3 年的分位是噪声；不足者当月不参与（不充数） |
| `top_n` | `5` | 16 个行业取最便宜的 ~31%，约等于"最便宜三分位"；比动量的 3 更分散——价值信号慢且单名噪声大 |
| `rank_buffer` | `2` | 迟滞消噪，R038 阈值带同源 |
| `rebalance_threshold` | `0.05` | 与 R038 `abs_band` 同源的先验常数 |
| `cooldown_days` | `0` | 月频本身即冷却 |

**v1 明确不做**（每一条都是"下一个增量"，不是遗漏）：
- 不做绝对估值闸门（"全都贵就持币"）——那是择时,与"择时不关键"哲学冲突,且多一个参数。
- 不做 PE/PB 多指标加权——多一组权重就多一层过拟合面（见 §5 红线）。
- 不做质量因子叠加（ROE 等）——防价值陷阱是真需求，但必须作为独立增量单独验收。

### 2.5 已知特性（不是缺陷，验收时如实报告）

- **价值陷阱**：便宜可能因为基本面在恶化（钢铁、地产近年即是）。v1 不设防，
  若失败且归因指向价值陷阱，D2 才引入质量因子。
- **左侧承受期**：买便宜的天然要熬，可能连续数月跑输后才兑现，短窗口回测对它不利。
- **分位窗口滚动**：`percentile_window=1250` 意味着 2020 年初的分位用的是 2015–2020 的历史，
  含 2015 股灾极值——这是真实可得信息，不算前视。

- `scripts/ingest_index_valuation.py` —— 已完成（2026-07-25）。
- `tests/test_platform_value_rotation.py`、`tests/test_index_valuation.py`。

**不动摇契约**（继承总蓝图 §4）：策略只产出目标权重；T 日信号 T+1 执行；执行细节全在
`execution.py`；状态即真相。"现任成员"必须从 `context.state.positions` 读，
保证回测/sim/live 三环路行为一致。

**前视防护（本课题最大的技术风险）**：加载层必须硬性截断到信号日，且
`ingest` 时已确认估值是**日频、当日发布**（由当日收盘价与最近已披露财报算出），
因此"T 日估值 → T 日信号 → T+1 执行"与价格类信号同构，无额外滞后需求。
财务报表类字段（`AIndexFinancialderivative`）**本课题一律不用**——那类按报告期编码、
有披露滞后，直接对齐即前视，要用需单独设计滞后规则。

## 4. 验收标准（按 AGENTS.md 全套，无豁免）

1. **pytest**：合成数据上验证——目标权重合法（非负、和 ≤ 1）；分位计算正确且无前视；
   Top-N 选最便宜；缓冲带黏性；历史不足者被排除；月频节奏（非月末不出目标）。
2. **训练样本对比**（end 2025-06-30）：候选 vs `domestic_industry_equal_weight`，
   **三滑点场景全跑**（default / stress / dynamic_participation）。
3. **起始日期敏感性**：从最早共同交易日起每 2 个自然月一个起点，截止 2025-06-30。
4. **报告指标**：年化收益、波动、最大回撤、Sharpe、换手、交易/订单/拒单数；
   附分年度表现，并声明窗口较短（5.3 年）的局限。
5. **冻结样本**（2025-07-01 之后）：仅在训练样本通过、参数冻结后一次性运行；见结果后不改参数。
6. **成功判据（先验声明，见结果前写死）**：训练样本上候选相对行业等权基线
   **年化超额 ≥ 2pp 或 Sharpe 明显占优**，且回撤不显著恶化、三滑点场景结论不翻转、
   敏感性排名稳定、冻结样本不打脸。
   不达标 → 判 `research-only`，按 Hard Rule 3 撤注册，结论写 `research-dashboard/notes/`。

## 5. 明确不做清单（红线，后续模型请勿"顺手"实现）

- **不做四因子加权评分**（估值 35% + 性价比 25% + 拥挤度 20% + 基本面 20% 这类）。
  权重无数据依据、因子间高度共线（价值/性价比/质量本是一族）、自由度对数据量的比例即过拟合定义。
  这正是 R028/R037 的死法。**因子只能一次加一个，各自独立验收，组合方式优先等权。**
- 不用 Wind 直接提供的 `PE_PERCENTILE` 类分位字段——口径与窗口不透明，可能含未来信息。
  分位一律自算，严格向后看。
- 不做参数网格搜索（Hard Rule 4；v1 先验冻结是特性不是缺陷）。
- 不做机器学习排序、舆情/新闻数据源、周频及更高频调仓、个股轮动。
- 不把估值信号叠加到 R038 核心仓——污染两边的可归因性。

## 6. 迭代路线（每项独立会话/PR，且仅在前一项通过后启动）

- **D1（本蓝图 v1）**：纯 PB 分位 + 缓冲带。先跑通、先验收。
- **D2 质量因子防价值陷阱**：引入 ROE 或净利润增速趋势否决"便宜但恶化"的行业。
  需先解决财报披露滞后的前视问题。作为 D1 的增量对照实验。
- **D3 拥挤度否决**：`turnover` 历史分位过高者禁止新开仓（数据已在库，零额外导入）。
- **D4 实战接入**：训练+冻结双过后建 `sim_r9_value_shadow` 影子组合跟跑 2–3 个月，
  再决定是否开真钱组合。此时才需要解决 §1.2 的数据日更问题。
