# Platform 看板界面标准

以 OpenAI Apps SDK UI 的灰阶、语义色和间距变量为准，结合 Open Design 的 OpenAI 页面观察，落地为独立的策略看板界面。上游原文件及许可证保存在 [design-reference](design-reference/)。

## 布局与排版

- 页面使用白底、浅灰侧栏、深灰正文和细灰边框。标题及指标通过字号和字重建立层级。中英文均使用系统无衬线字体，金融数字使用等宽数字样式。
- 控件、导航项和卡片圆角依次使用 8、10、12 px。主内容边距在 12 至 24 px 间随视口变化。侧栏触控区域高 44 px，桌面支持收起，移动端使用抽屉。
- 主区宽屏铺开。首页优先显示组合，其次显示最近回测和配置分布。窄屏采用单列，密集表格在各自容器内横向滚动。
- 标题、筛选区和分析模块围绕任务组织。页面省去独立的产品标语、重复标题和空说明。

## 数据与交互

- 红色表示上涨或买入，绿色表示下跌或卖出。对比线、场景和相关性图使用辅助颜色、图例和线型。
- 控件保留键盘焦点，当前导航和分段按钮提供语义选中状态。读数失败提示原因，缺失数值用破折号，空表提示当前状态。
- 正式回测默认展示，临时回测由全局开关控制。组合快照区间仅改变图表，最新持仓仍取最新账户快照。
