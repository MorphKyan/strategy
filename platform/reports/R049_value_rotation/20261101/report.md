## 1. 假设

R039（追涨的动量轮动）在行业层面失败后，本课题检验**方向相反**的假设：

> 在同一 16 行业池、同一执行口径下，买入**相对自身历史便宜**（PB 时序分位最低）的
> 5 个行业，能否跑赢"持有全部行业等权"？

对照基线 `domestic_industry_equal_weight.yaml`（同池、同费用、月频等权）。
成功判据在见结果前写死于蓝图 §4.6：训练样本年化超额 ≥ 2pp 或 Sharpe 明显占优，
且回撤不显著恶化、三滑点场景不翻转、敏感性稳定、**冻结样本不打脸**。

## 3. 过程中发现并修复的两个缺陷（对全平台有效）

### 3.1 份额折算后清仓卖不掉（执行引擎缺陷，影响所有策略）

`execution.py` 的卖出数量钳制原本写作
`min(planned, _round_quantity(position.quantity, lot))`，而 `round_mode="round"` 会
**向上取整**。512200 房地产ETF 于 2024-08-09 做 1:0.3581 份额折算后持仓变成
**207,260.74 股**（非整数），钳制值被取整到 207,300 > 实际持仓，订单判
`insufficient_position` 并按 `retry_next_day` 每日重试，**该行业实际上永远清不掉**
（训练样本里因此产生 39 笔连续拒单）。

修复：新增 `_floor_to_lot()`，卖出上限一律向下取整到整手，任何 `round_mode` 下都不超卖，
零股余额留在账上。已加回归用例
`test_sell_quantity_never_exceeds_fractional_position_after_split`。
凡持有过做过份额折算标的（510300/511260/518880/512200/510500/510880）并执行过清仓的
历史结论，均可能受此影响。

### 3.2 候选与基线入场约定不一致（对比方法学缺陷）

基线 `monthly_equal_weight` 覆写 `should_check_rebalance` 实现**首日建仓**，
而候选沿用基类只在月末交易，导致每次回测开头**最多空仓约 22 个交易日**。
在 2024-09 政策行情（数日 +30%）起点上，基线首日满仓吃到 +32.6%、候选空仓等到
09-30 才在高位买入（-17.0%），**单这一项造成 -49.6pp 的伪劣势**。

修复：候选实现同语义的 `should_check_rebalance`（`rebalance_on_start` 默认 True）。
这是消除对比不公平，不是调参改善指标——修复后训练样本超额反而**从 +3.30pp 降到 +2.60pp**。
本报告全部指标均为修复后重跑所得。

## 6. 起始日敏感性（32 个起点 × 3 场景）

| 口径 | 超额 > 0 | 年化超额中位 | 回撤更优 | Sharpe 占优 |
|---|---|---:|---|---|
| 全部 32 起点（default） | 19/32（59%） | +1.38pp | 25/32 | 20/32 |
| 全部 32 起点（stress） | 18/32（56%） | +1.27pp | 24/32 | 19/32 |
| 窗口 ≥ 2 年的 20 起点（default） | **19/20（95%）** | +2.91pp | **20/20** | — |
| 窗口 ≥ 2 年的 20 起点（stress） | 18/20（90%） | +2.86pp | 20/20 | — |

排名结论在三个滑点场景间不翻转。但存在清晰的**时间分层**：2020-03 至 2023-05 的起点
几乎全为正（+0.1 ~ +5.8pp），2023-07 之后的起点几乎全为负（-0.2 ~ -8.8pp，
2025-05 起点因窗口仅 45 天年化失真至 -33.0pp）。这一分层在冻结样本上被放大验证。

## 7. 冻结样本（2025-07-01 → 2026-07-24，260 观测）——**决定性失败**

| 指标 | 候选 | 基线 | 差异 |
|---|---:|---:|---:|
| 累计收益 | **-8.80%** | **+20.49%** | **-29.29pp** |
| 年化收益 | -8.55% | 19.80% | -28.35pp |
| 年化波动 | 15.94% | 18.36% | -2.42pp |
| 最大回撤 | -21.65% | -11.10% | -10.55pp（更差） |

| 拒单数 | 0 | 1 | -1 |

stress 与 dynamic_participation 场景结论一致（累计 -8.88% / -8.80%）。

### 7.1 败因：价值陷阱 + 成长行情

冻结期各行业后复权涨跌与候选期末持仓（★）：

| 行业 | 涨跌 | | 行业 | 涨跌 |
|---|---:|---|---|---:|
| 5G通信 | **+160.7%** | | 证券 | -2.7% |
| 半导体 | **+113.2%** | | 钢铁 | -3.6% |
| 科技 | **+95.4%** | | 军工 | -5.8% |
| 有色 | +51.7% | | 银行 | -7.4% |
| 新能车 ★ | +25.2% | | 传媒 | -12.9% |
| 煤炭 | +24.1% | | 地产 | -16.9% |
| 家电 ★ | +1.7% | | 消费 ★ | -17.4% |
| 医药 ★ | -1.4% | | 白酒 ★ | -24.6% |

**期末持有 5 只均值 -3.3%，全池等权 +23.7%。** 涨幅前三（5G通信、半导体、科技）
全部因 PB 分位偏高被系统性回避，而候选实际持有的消费、白酒是典型**价值陷阱**——
便宜是因为基本面在恶化，且在此期间继续变得更便宜。

这正是蓝图 §2.5 事先声明的已知风险，v1 有意不设防（防陷阱需质量因子，属独立增量）。
冻结样本以最直接的方式证明：**在成长主导的行情中，纯估值分位不仅无效，而且是反向指标。**

## 8. 结论与建议

**判定：Failed / research-only。** 训练样本达标但冻结样本以 -29.29pp 决定性打脸，
符合蓝图 §4.6 的不达标条款与 AGENTS.md 验收指引（"fails final testing → Failed"）。

处置（已执行）：
- 策略按 Hard Rule 3 **撤销注册**，代码保留为 research-only（含 pytest）；
- 候选配置 `r9_value_rotation_industry.yaml` 删除；基线 `domestic_industry_equal_weight.yaml`
  与 16 只行业 ETF 数据链、估值数据链保留；
- 结论写入 `research-dashboard/notes/R049_industry_value_rotation.md`。

**沉淀的可复用资产**（本次课题最有价值的产出）：
1. **执行引擎超卖缺陷修复**（§3.1）——影响所有策略，含实盘；
2. **入场约定一致性**（§3.2）——今后任何新策略与基线对比前必须核对此项，
   否则敏感性测的是入场运气。R039 亦沿用基类月末入场，其结论存在同类污染
   （但其劣势达 10.5pp，远超入场时点可解释的量级，不推翻其 Failed 判定）；
3. **行业指数估值数据链**（入库脚本 + 映射表 + 加载层 + 前视防护），
   D2/D3 若做质量因子或拥挤度可直接复用。

**对后续研究的判断**：R039（动量/追涨）与 R049（估值/抄底）在同一行业池上双双失败，
方向相反却同样跑输等权。这构成对"行业轮动"这一课题本身的强证据——
**在 A 股行业 ETF 层面，横截面择时（无论用什么信号）都难以战胜简单等权持有。**
建议卫星仓不再沿轮动方向迭代（D2 质量因子、D3 拥挤度的预期收益已显著下降），
若仍要开卫星仓，优先考虑"行业池等权 + Swedroe 阈值带"这类**不做选择、只做纪律**的形态——
这与 R038 在核心仓的成功经验一致，也与本平台反复验证的铁律一致：**简单纪律赢复杂机制。**
